#  Restaurant Rating Prediction Model

This project is a **Machine Learning model that predicts the rating of a restaurant** using information such as votes, location, cost, and other restaurant-related features.

I created this project to get practical experience with **regression problems** and to understand how different restaurant features can be used to predict a numerical rating.

##  About the Project

The main goal of this project is to predict a restaurant's **aggregate rating** based on the information available in the Zomato dataset.

Instead of manually estimating a restaurant's rating, the machine learning model learns patterns from existing restaurant data and uses those patterns to make predictions for new data.
